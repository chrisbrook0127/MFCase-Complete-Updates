# MFCase Complete project rules
Maintain the existing combined application independently from standalone MFCase and PDF Combiner. Historical approved configuration: copy learning, manual combination, combine-only undo and nested folders. These are preservation requirements to verify against the exact current Complete source, not authorization to change any application behavior.
Preserve originals, collision-safe output, selective undo, reviewed case grouping and existing OCR, review and local learning behavior. Do not alter thresholds, inference, recognition engines, file movement or learning eligibility incidentally. Keep user PDFs, case identifiers, data, credentials and logs out of public GitHub and CI. No sharing learning data with standalone applications except the approved copy workflow.
Preserve separate installer, version stream, local data and updater. Confirm the real feed and rollback procedure before any release. No application modifications or publication are authorized by infrastructure setup. Test only approved source and synthetic inputs. Record missing source as a blocker, not a passing application test.
