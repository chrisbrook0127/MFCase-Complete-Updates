# MFCase Complete CI adapter
The public update repository contains no verified application source, installer or updater package. The real Windows infrastructure workflow is therefore intentionally limited to verifying the setup branch's exact original tracked blobs, allowed added infrastructure files and archive safety checks using synthetic ZIP fixtures. It does not certify application behavior, packaging, updater, Windows GUI or recognition.
Canonical commands: Python 3.11 standard library; python -m unittest discover -s tests -p test_infrastructure.py -v; python scripts/verify_infrastructure.py setup. The setup check validates repository identity from git origin and GITHUB_REPOSITORY when present, and the committed tree against the immutable original baseline and exact infrastructure allowlist. This guard is specifically for the setup PR, not a blanket restriction on subsequent authorized development. No publication or network transfer of data. A failed or skipped test must fail validation.
For an authorized locally available candidate archive, python scripts/verify_infrastructure.py archive --archive <path> --sha256 <independently approved digest> checks the real SHA-256, ZIP structure, safe Windows destinations and CRC; it does not extract, upload or run the source. This is not full application validation or an approval mechanism.
